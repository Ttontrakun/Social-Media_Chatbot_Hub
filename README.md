# socialmedia_chatbot_hub

ต้นแบบหน้า Unified Inbox (LINE / Facebook / Instagram / X) แบบ frontend ล้วน กดใช้งานได้
ยังไม่มี backend จริง ข้อมูลทั้งหมดเป็นข้อมูลจำลองในหน้าเว็บ

## รัน

```
docker compose up -d --build
```

เปิด http://localhost:8080

หยุด: `docker compose down`

## ข้อควรรู้

- หน้า Login/สมัครสมาชิกเป็นของจำลอง ไม่ตรวจรหัสผ่านและไม่บันทึกรหัสผ่าน
- ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ (แยกตามอีเมล) ล้างได้ที่ ตั้งค่าบอท > รีเซ็ตเป็นข้อมูลตัวอย่าง
- ช่องทาง LINE/Facebook/Instagram/X เป็น flow จำลอง ไม่ได้ติดต่อแพลตฟอร์มจริง และไม่เก็บ secret/token
- `frontend/api.js` คือชั้นเรียกข้อมูล เมื่อมี backend ให้แก้เฉพาะไฟล์นี้

## ตัวเลขแจ้งเตือนในรายการแชท

- **สีแดง**: ลูกค้ากำลังรอพนักงาน (ขอคุยกับพนักงาน, ถูกส่งต่อ, หรือบอทตอบไม่ได้) เรียงไว้บนสุดและมีตัวเลขรวมที่เมนู "แชท"
- **สีดำ**: มีข้อความใหม่แต่บอทดูแลอยู่ ไม่ต้องรีบเข้าไปตอบ

## แดชบอร์ด

กราฟ 5 ชุด (ข้อความต่อวันแยกช่องทาง, บอทกับพนักงาน, ช่องทางยอดนิยม, ช่วงเวลาที่ลูกค้าทัก, หัวข้อที่ถามบ่อย) เลือก 7/30 วัน และสลับเป็นตารางได้ ข้อมูลย้อนหลังเป็นข้อมูลตัวอย่าง ส่วนของวันนี้รวมข้อความที่กดจำลอง กราฟอยู่ใน `frontend/charts.js` (ไม่พึ่งไลบรารีภายนอก)

## สิ่งที่กดได้

- Login / สมัครสมาชิก / ออกจากระบบ (ปุ่มวงกลมล่างสุดของเมนูซ้าย)
- ช่องทาง: เชื่อม LINE ด้วยฟอร์ม Channel ID/Secret/Token พร้อม Webhook URL, เชื่อม Facebook/Instagram/X ด้วยหน้าจำลอง OAuth + เลือกเพจ, จำลอง token หมดอายุ (ส่งข้อความไม่ได้จนกว่าจะเชื่อมใหม่)
- มือถือ: เลือกแชทแล้วมีปุ่ม "กลับ"

- กล่องข้อความ: กรองช่องทาง, ค้นหา, เลือกแชท, สลับโหมด Bot/พนักงาน, พิมพ์ตอบ, ใช้ AI ร่างคำตอบ, ปิดเคส, ปุ่ม "จำลองข้อความเข้ามา" (บอทตอบจากเอกสารในฐานความรู้)
- ตั้งค่าบอท: บทบาท/น้ำเสียง, โหมดตอบอัตโนมัติ หรือ ร่างให้แอดมินกดส่ง, หัวข้อที่ส่งต่อพนักงานเสมอ, ข้อความเมื่อไม่พบคำตอบ (มีผลทันทีกับปุ่ม "จำลองข้อความเข้ามา")
- ฐานความรู้ RAG: อัปโหลด/ลบเอกสาร (จำลองการ embed)
- ช่องทาง: เชื่อมต่อ/ตัดการเชื่อมต่อ และเปิด-ปิด Bot ต่อช่องทาง
- Integrations/API: ตั้ง webhook, ส่งทดสอบ, สร้าง API key ใหม่ (จำลอง), ดู log เหตุการณ์
- แดชบอร์ด: สถิติจากข้อมูลจำลอง

## ขั้นต่อไป

เพิ่ม backend (FastAPI/NestJS), Postgres + pgvector, Redis, และ adapter ของแต่ละแพลตฟอร์มใน docker-compose.yml
